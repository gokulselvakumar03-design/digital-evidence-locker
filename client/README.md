# Frontend Application (`client`)

React + TypeScript web client for the Digital Evidence Locker & Legal Workflow Platform.

## Features
- Shadcn UI primitives + Tailwind CSS dark-mode design system.
- Web Crypto API for client-side SHA-256 evidence hashing before upload.
- Chain-of-custody evidence preview and audit log UI.

## Getting Started
```bash
npm install
npm run dev
```
Runs dev server at `http://localhost:3000` or `5173`.
